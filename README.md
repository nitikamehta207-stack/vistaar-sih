# Vistaar — Digital Capacity Building & Learning Portal

React + Vite + Tailwind + React Router + Recharts + Lucide. Frontend prototype with mock data.

## Run
    npm install
    npm run dev

## Demo access
Use the role tabs on the Login page (Trainee / Trainer / Admin) — no real credentials needed.

## Structure
src/components/{ui,layout,dashboard,courses}, src/pages/{public,auth,trainee,trainer,admin},
src/data (mock data), src/context (Auth + App state), src/routes, src/utils
